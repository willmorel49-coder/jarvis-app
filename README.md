# Intégral Pharma · App

Application mobile-first pour les équipes commerciales pharmaceutiques.

## Accès rapide
- **App live** : https://willmorel49-coder.github.io/jarvis-app
- **Repo** : https://github.com/willmorel49-coder/jarvis-app

## Fonctionnalités
- Catalogue produits avec recherche et filtres
- KPIs temps réel (CA, marge, rotation)
- Top produits par gain
- Fiches produit détaillées
- Multi-profils (commercial, manager, direction)

## Tech
- HTML/CSS/JS vanilla — aucune dépendance
- Déployé sur GitHub Pages

## Déployer une mise à jour
```bash
cd ~/jarvis/APP
git add .
git commit -m "description de la modif"
git push
```
L'app se met à jour automatiquement en 1-2 minutes.
