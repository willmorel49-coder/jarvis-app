## Equipe de sous-agents disponible

Pour toute demande large, passe par `tech-lead-orchestrator` qui delegue.
Routing rapide :
- Donnees / pipelines / scraping -> data-pipeline-engineer
- Codes produits / jointures -> pharma-data-modeler
- Sortie Excel -> excel-report-engineer (standard maison obligatoire)
- Regle de calcul metier -> valider avec pharma-domain-expert
- Avant de livrer un chiffre -> data-quality-validator
- Front / dashboard -> dashboard-frontend-dev, dataviz-specialist, ui-ux-polish
- Avant commit/push -> security-auditor
- Donnees client -> rgpd-compliance-officer
- Bug / ecart de chiffre -> bug-hunter
- Apres toute modif -> code-reviewer
