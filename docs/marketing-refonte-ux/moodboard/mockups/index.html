Ce que je propose de coder ensuite

1Inspector contextuel — au lieu des 3 onglets fixes Apparence/Contenu/Données, il change selon ce que tu sélectionnes. Sélection block image → contrôles image. Sélection prix → contrôles prix. Sélection rien → contrôles page globale.
2Slash menu / — taper / dans une ligne vide ouvre le menu d'insertion (Produit IP, OFFILOG, Sagitta, Tableau, Mention légale, Bloc remise).
3Floating pill toolbar — sélection texte fait apparaître une barre noire flottante au-dessus avec Bold/Italic/Color/Lien.
4Drag handle au hover — icône ⋮⋮ apparaît à gauche de chaque block au survol, pour réordonner par drag.
5Geist Mono pour les chiffres — prix, CIP13, pourcentages, MOQ. Plus pro, plus lisible.
6Toggle densité compact / cozy — pour les commerciaux qui veulent voir plus de produits sans scroller (à la Linear).
